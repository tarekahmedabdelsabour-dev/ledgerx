## I don't see a new module after the update

Run the migration and clear the cache, then refresh the browser with `Ctrl + Shift + R`. Make sure the user has a Role that allows the module.

## I can't edit a document

A submitted document cannot be edited. Cancel it and then amend it, or create a return or an adjustment entry.

## The numbers in the report don't match my expectation

Check the company, period, and Cost Center in the filters, and that all documents are **submitted**, not draft.

## An error message when saving

Read the text of the message, as it usually names the missing field or the incorrect account. If the cause isn't clear, copy it and send it to the system administrator.

## How do I change the language

From **My Settings**, or from the language switcher on the login page.

## How do I search for anything

`Ctrl + K` inside the system. In this guide too, `Ctrl + K`.

## How do I print this guide or save it as a PDF

Click the download icon at the top of the page and choose **Save as PDF** from the print dialog.

A Journal Entry is the manual tool for recording any accounting transaction that other documents do not cover.

## Creating an entry

1. Open a new **Journal Entry** and set the date and the type (Journal Entry, Opening Entry, Depreciation...).
2. Add the rows: account, debit or credit, and the Cost Center when needed.
3. Make sure **total debit = total credit**.
4. Save then submit.

## When to use it

- Opening balances.
- Accrued and prepaid expenses.
- Bank reconciliations and currency differences.
- Correcting errors between accounts.

## A row for a Customer or Supplier

When using a receivable or payable account you must choose the **Party Type and the Party**, so that the entry appears in the party's account statement.

> Entries created automatically by modules (such as payroll or reservations) are not cancelled manually. Cancel the original document and its entry will be cancelled.

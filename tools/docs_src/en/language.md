## Switching language

From **My Settings** choose the preferred language (Arabic or English). The interface and the direction change from right to left or the reverse. There is also a language switcher on the login page.

## Appearance

Choose light or dark mode from the user menu. This guide has a separate switch for each of language and mode at the top of the page.

## Visual identity

The LedgerX logo, icons, and colors are applied to the login page, the home screen, print reports, and emails. The system administrator can change the logo from **Website Settings**.

## Printing

Documents use the LedgerX print style with a light watermark. You can create your own **Print Format** for any document.

## Custom fields and reports

- **Custom Field**: add a new field to any document.
- **Report Builder**: create a report from any document with filters and columns.
- **Workflow**: add sequential approvals to documents.

## Adding a user

1. Open **User** and add a new user by email.
2. Enter the name and the preferred language.
3. From the **Roles** tab, select what they need (Accountant, Sales Manager, Stock Keeper...).
4. Save, and the user receives a link to set their password.

## Roles

A Role is a set of permissions: read, write, create, delete, submit, export. A user can be given more than one Role. From the **Role Permissions Manager** you set what each Role can do on each document type.

## Restricting data (User Permissions)

To restrict a user to a specific branch, Warehouse, or company, add a **User Permission** for them, and they will see only the records linked to it. This is very useful in multi-branch companies.

## Account security

- Use strong passwords, and enable two-factor authentication for managers.
- Disable an employee's account when they leave instead of deleting it, so the record of their operations remains.
- Review the **Activity Log** to see who changed what and when.

> ! Do not share the manager account between more than one person, as this undermines auditing.

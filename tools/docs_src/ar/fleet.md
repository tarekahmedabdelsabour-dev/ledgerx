## ما تغطيه الوحدة

| المجال | السجلات |
|---|---|
| الأساس | المركبة، السائق، نوع المركبة، إسناد السائقين، مستندات الأسطول (الترخيص والتأمين) مع تنبيه الانتهاء، الإطارات |
| الصيانة | خطط الصيانة، جداول الصيانة بالكيلومترات أو الأيام، أوامر العمل (مهام وقطع وعمالة)، سجل الوقود |
| التشغيل | الرحلات، عقود الإيجار، المخالفات المرورية، الحوادث |
| التتبع | أجهزة GPS ومواقع المركبات |

## الاستخدام اليومي

1. أضف المركبات والسائقين وأسندهم.
2. سجّل مستندات كل مركبة بتواريخ الانتهاء، وسيصلك تنبيه يومي قبل الانتهاء.
3. أنشئ خطة صيانة وطبّقها، فيظهر **قريب الاستحقاق** و**متأخر**.
4. سجّل تعبئة الوقود ليحسب النظام الاستهلاك لكل 100 كم.
5. أنشئ **رحلة** بمصروفاتها وإيرادها، وفوترها للعميل.
6. للإيجار: أنشئ **عقد إيجار** بعدة مركبات وكيلومترات مجانية، وسيُحسب الزائد والأضرار ويُنشأ الفاتورة.

## المخالفات

تُحمَّل المخالفة على الشركة أو السائق أو العميل. إذا حُمّلت على سائق يمكن خصمها من راتبه.

## التقارير

انتهاء المستندات، استحقاق الصيانة، تكلفة المركبة، استهلاك الوقود، وربحية الرحلات.

## الأدوار

**مدير الأسطول** له كل الصلاحيات. **مشغّل الأسطول** يسجّل الرحلات والوقود فقط.

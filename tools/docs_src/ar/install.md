> هذه الصفحة لمسؤول النظام.

## التحديث

```
cd <مجلد-النظام>/apps/<اسم التطبيق>
git pull origin main
cd <مجلد-النظام>
bench --site mysite.localhost migrate
bench --site mysite.localhost clear-cache
```

ثم أعد تشغيل الخدمات وحدّث المتصفح بالضغط على `Ctrl + Shift + R`.

## تثبيت وحدة جديدة

1. انسخ التطبيق إلى مجلد التطبيقات.
2. أضفه إلى قائمة التطبيقات وثبّته بحزمة بايثون.
3. ثبّته على الموقع ثم نفّذ الترحيل ومسح الذاكرة المؤقتة.
4. أعد التشغيل الكامل.

> ! إذا أضفت التطبيق للقائمة دون نسخه وتثبيته، لن يعمل الخادم. تحقق من اكتمال كل الخطوات.

## النسخ الاحتياطي

نفّذ `bench --site mysite.localhost backup --with-files` بشكل دوري واحفظ النسخ خارج الخادم.

## أول خطوات عند المشكلات

- افتح **سجل الأخطاء** من النظام وانسخ نص الخطأ.
- جرّب مسح الذاكرة المؤقتة وإعادة التشغيل.
- راجع أن كل الوحدات مثبّتة على الموقع.
